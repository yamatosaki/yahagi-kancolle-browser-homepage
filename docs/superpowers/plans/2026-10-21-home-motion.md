# 首页开场动画

**目标：** 在现有蓝白首页上增加工业科幻风格的启动序列、首屏入场和轻微指针视差。用户已确认效果，并要求移除重播开场按钮后同步源码和发布官网。

**实现边界：** 原生 CSS 与 JavaScript，不增加依赖。保留原有立绘、文案、字标、下载与导航。仅首页启用，其他页面沿用现有行为。

- [x] 在 `index.html` 添加默认隐藏的启动界面、进度刻度和跳过按钮，保留首页状态行，不提供重播入口。
- [x] 在 `src/home-motion.js` 管理启动、资源等待、超时退出、会话去重、键盘跳过与减少动态偏好。
- [x] 在 `src/home-motion.css` 实现准星、扫描、擦除及分层入场；指针视差仅在精细指针设备启用。
- [x] 在 `src/main.js` 接入首页动画，在 `src/locales/site.js` 补齐交互文案的四种翻译。
- [x] 检查桌面、手机、跳过、减少动态、资源异常和原有下载交互；运行 `npm test` 与 `npm run build`。

启动进度表示视觉序列进度，不表示网络字节下载比例。首屏图片等待有上限；关闭脚本时动画层保持隐藏，页面直接可用。系统减少动态设置生效时跳过开场和视差。开场按标签页会话仅自动播放一次。开场字标与首页使用相同的斜切和双划线，保留已确认的单行大字号。
