# 全站文字层级与宽屏可读性

**目标：** 统一相同语义角色的字号，让 2K、4K 屏幕上的说明、操作、日期和正文清晰可读，并协调组件空间。沿用现有字体、配色、字标和页面内容。

**实现：** `src/typography.css` 定义 caption、meta、small、body、lead、subtitle、section、page 八个共享文字层级；页面组件引用变量。窄屏统一覆盖变量值，避免同类组件各自定义小字号。已确认的品牌字标与导航保留独立设计尺寸。

正文使用 body；日期、版本、计数使用 meta；操作与辅助说明使用 small；卡片标题使用 subtitle；模块标题使用 section。英文分类与装饰标记使用 caption。页面引言使用 lead，页面主标题使用 page。标题保留明确的层级，长正文保留可读行宽，下载来源与安装链接行为不变。
