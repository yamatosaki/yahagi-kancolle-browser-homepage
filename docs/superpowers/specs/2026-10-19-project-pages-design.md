# 项目信息页面扩展

用户要求新增三个独立页面，沿用冷白、墨黑、钴蓝及现有轻量导航，本轮仅本地开发。

- `disclaimer.html`：逐字保留用户提供的两段免责声明；页脚全站可达。
- `updates.html`：展示官方 GitHub Releases 全部已发布版本；左侧版本索引、右侧正文，手机使用版本选择器。默认最新版本，URL hash 记录版本，可返回和分享。保留发布日期、预发布标记和原始发布页链接。
- `support.html`：采用仓库 README/FUNDING 公开的支付宝、微信和 GitHub Sponsors 渠道；收款码原文件直接保存在本地，不修改内容。保留参与开发入口与特别致谢，包含 iOS 移植、POI 社区、框架维护者、测试反馈玩家和舰娘 WIKI 的数据支持，不单独展示开源资料来源区，不虚构赞助人名单。
- 主导航添加更新日志和赞助与致谢，页脚添加三个新页面。窄屏导航保持可用，首页页脚延续紧凑布局。
- 日志通过手动脚本抓取官方 API、原样保存 Markdown，网页读取静态 JSON；Markdown 用 Marked 解析并由 DOMPurify 清理。

验收：六个 HTML 构建成功；页面与相对链接可达；9 个公开版本可选；日期/链接/正文与 API 一致；免责声明文本准确；赞助素材和致谢均可追溯；桌面与手机无横向溢出；不部署。
