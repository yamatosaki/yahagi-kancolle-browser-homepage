# ヤハギ官网 · 本地 UI 规格

2026 年 10 月 19 日确认的当前实现范围。先在本地完善界面，再另行处理部署。

## 视觉与内容

- 六页统一使用冷白 `#F7F8FA` 背景、墨黑 `#111318` 文字与钴蓝 `#2456FF` 强调色，采用先锋杂志方向。
- `index.html` 为独立首页，只呈现左侧彩色矢矧大头、产品文案、倾斜切痕 YAHAGI 字标、Android/iOS 入口及页脚。顶部过渡、边缘消隐与背景渐变由 CSS 实现，大头素材可独立替换。
- 全站共享轻量导航，主导航包含首页、功能、下载、更新日志及赞助与致谢，直接跨页跳转；免责声明从页脚进入。导航、字标、文案与按钮均为真实界面元素。900px 及以下使用手机菜单，901px 起使用桌面导航。
- 首屏图片路径由 `src/site-config.js` 的 `heroAssets.portrait` 管理；位置与尺寸使用 `--portrait-width`、`--portrait-x`、`--portrait-y`，桌面与手机分别适配。
- `features.html` 为独立功能页，采用六组纯文字：舰队与战斗、任务中心、改修开发远征、编成与海域资料、航海日志备份、多屏移动体验。每组包含编号、标题、说明与三条详情。
- `download.html` 为独立浅色下载页，提供 Android/iOS 入口、版本信息和发布记录链接。网站不展示应用截图，也不设置使用指南。
- `updates.html` 展示 GitHub Releases 静态快照；`support.html` 提供赞助、参与开发与特别致谢，包含舰娘 WIKI 的数据支持；`disclaimer.html` 使用用户确认的两段原文及相关文档链接。
- 原有海港背景、前景立绘及三张应用截图保留为历史素材，当前页面不引用。

## 下载交互

- 首页和下载页的 Android/iOS 入口分别打开当前平台的四来源弹窗，弹窗内不切换平台。
- 每个平台提供百度网盘、夸克网盘、GitHub、直接下载四个来源。
- 百度与夸克的 `url`、`code` 暂留空，显示禁用占位；后续在 `downloads[].sources` 填入对应平台的真实链接与可选提取码。
- GitHub 指向 v1.0.8 发布页；直接下载分别指向已核实的 APK、IPA 资产。
- Android 是项目主要维护的平台；iOS 弹窗在安装方式说明的下一行显示“iOS 移植版由 Kutinana 提供”，首页和下载页的入口不显示署名。
- 弹窗打开后聚焦关闭按钮，支持键盘关闭、可用来源访问与关闭后焦点返回；手机导航可用，减少动态偏好时关闭非必要运动。

## 更新与项目资料

- `src/data/releases.json` 当前保存 1.0.0–1.0.8 共 9 个公开版本，保留原始 Markdown、名称、发布时间与 GitHub 发布链接。
- 更新页通过桌面版本索引或手机选择框阅读单个版本，支持版本 URL、前进后退与切换标题播报；原始发布页始终可访问。
- `src/release-notes.js` 采用 Marked 解析 Markdown、DOMPurify 清理 HTML。浏览器读取本地静态快照，不直接调用 GitHub API。
- `npm run sync:releases` 从官方 API 分页同步，跳过草稿并在完整成功后替换快照；同步完成后再构建，构建命令不会自动刷新日志。
- 支付宝、微信二维码原样取自公开仓库 `docs/images/sponsors/`，本地文件位于 `public/assets/support/`。原生 `details` 展开并链接原图，图片内容不作修改；来源 URL 与校验记录见 `docs/ASSETS.md`。
- 赞助与特别致谢保留可追溯的公开链接，不单独展示开源资料来源区，不虚构赞助人名单；完整来源记录保存在 `docs/ASSETS.md`。

## 构建结构

Vite 8 通过 `vite.config.js` 中的 `build.rolldownOptions.input` 配置六个 HTML 入口，共享脚本按当前页面存在的内容容器初始化。新页样式独立存放在 `src/project-pages.css`，由共享 `src/styles.css` 使用 `@import` 引入。构建使用相对路径，兼容未来 GitHub Pages 仓库子路径。

## 本地验收

Vite 生成六个 HTML 页面且本地预览均可打开；主导航及页脚入口正确；首页只加载彩色大头；功能页六组文字完整；平台弹窗四来源匹配；九个版本正文、原始链接与前进后退正确；二维码展开并可查看原图；免责声明两段原文保持一致；手机布局与键盘交互可用。
